# MyLoAI Control Center macOS Packaging

The macOS release is a bundled application named **MyLoAI Control Center**, distributed as a `.app` bundle and disk image.

The production installer must contain only the application, runtime dependencies/resources, required redistribution notices, installer metadata, and concise end-user help.

Repository-only material such as `archive/`, `.github/`, `tests/`, agent prompts, contributor documentation, and internal project analysis must not be included.

The packaged application should expose the product as MyLoAI Control Center and preserve existing application behavior.
